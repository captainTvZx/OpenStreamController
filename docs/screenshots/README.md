# Screenshots

Drop the images here using these exact filenames and they will show up in the main
[README](../../README.md) with no further edits:

| File | What to capture |
| --- | --- |
| `deck.png` | The deck tab: program preview, button grid, mixer with the volume meters, health row |
| `scenes.png` | The scenes tab: scene list, studio mode, transition controls |
| `sources.png` | A scene's source list, or the source sheet opened on one of them |
| `connect.png` | Adding a computer: QR scan, Wi-Fi scan or the manual fields |
| `button.png` | The button editor: action picker, colour and icon |

Tips:

- PNG, taken on a device or simulator with a populated scene collection — an empty OBS looks broken.
- Landscape shots of a tablet show the deck layout best; the phone screenshots read better in
  portrait.
- Keep each file under ~1 MB so cloning the repository stays quick.
- If you rename a file, update the image links in the main README to match.
